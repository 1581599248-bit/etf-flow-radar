# 资金ETF流动每日跟踪

面向客户的 A 股 ETF 日报网站。系统只使用真实公开数据，在交易所完成上一交易日日终份额披露后自动更新；GitHub Pages 与 Render 共用同一份静态构建产物。

## 日报回答什么

- 今日盘面：A 股股票 ETF 估算净申赎、流入/流出分布、宽基、风格、申万一级行业与热门主题切换。
- 宽基体系：覆盖上证、沪深、中证、深证、创业板与科创板主要宽基系列。
- 两张坐标图：横轴为 20 日相对沪深300收益，纵轴为 5 日端点份额变化估算占 5 日前参考规模的比例。
- 客观补充：价格—资金状态、ETF份额增加/减少只数、单只ETF贡献集中度与数据质量。
- 客户交付：手机端适配，支持高清 JPG 导出。

## 核心数据口径

### 1. 一日资金流

主口径：

`1日估算净申赎 =（T日日终份额 − T-1日经公司行动调整后的可比份额）× T日参考价格`

参考价格优先使用同日成交均价（成交额÷成交量）；若成交均价/收盘价与同日 NAV 明显不一致，则回退同日 NAV。该金额用于观察申购赎回方向与量级，不等于基金公司最终现金流。

### 2. 份额主源与交叉核验

- 沪市、深市 ETF 日终份额：交易所公开数据，AKShare 仅作为采集适配层。
- 第三方“最新份额”：只做交叉核验，**不得覆盖交易所官方份额**。
- 当份额发生接近 2 倍、3 倍、1/2、1/3 等异常跳变时，系统使用精确交易日 NAV 的反向比例变化确认拆分/合并；确认后将历史份额调整到同一份额单位再计算资金流。
- 无法解释的超大单只 ETF 资金变化触发熔断，禁止覆盖上一份已验证快照。

### 3. A股股票ETF市场总量

市场总量先按精确交易日基金类型筛选股票型 ETF，再剔除跨境、债券、商品、货币等非 A 股股票品种。市场总量**不依赖行业/主题分类是否完成**，因此新增或待归类 ETF 不会因为分类缺失而从全市场资金总量中消失。

### 4. 5日 / 20日

当前 5 日、20 日字段是“端点份额变化估算”：期末份额减去 5/20 个交易日前的可比份额，再乘期末参考价格。它用于观察中期份额方向，**不等同逐日资金流之和**，因此页面与方法说明不得称其为“5日累计净流入”或“20日累计净流入”。待历史逐日参考价缓存积累完整后，可升级为逐日资金流求和口径。

### 5. 行业与主题

每只 ETF 只有一个叶子归属，避免市场总量重复计算；但行业展示采用两层结构：

- 申万一级行业：按 SW2021 一级行业父级汇总。
- 热门主题：半导体、芯片、消费电子、AI算力、创新药、机器人等作为一级行业下的子主题单独观察。

因此“半导体”不会再被误称为“申万一级行业”，电子一级行业会完整包含其半导体/芯片/消费电子等子主题 ETF。

## 自动更新

生产入口固定为：

`python data_pipeline/update_daily_production.py`

`.github/workflows/daily-etf-data.yml` 在周二至周六（对应周一至周五交易日）北京时间 05:00、06:00、07:00、08:00 检查是否出现新的完整交易日数据。并发策略为 `cancel-in-progress: true`，避免上一次长任务未结束时重复跑重型任务。

每次生产发布按以下顺序执行：

1. 单元测试。
2. 获取最新完整交易日与 21 个交易日份额窗口。
3. 执行交易所份额、第三方交叉核验、公司行动、价格/NAV一致性、ETF总数、重复代码、分类覆盖和资金对账检查。
4. 构建静态页面并运行前端测试。
5. 只有通过质量门槛才更新 `site/data/latest.json`、历史快照和完整 ETF 名册；失败时保留上一份已验证数据。

如果已经发布了同一交易日，后续定时任务只做最新交易日探测并直接退出，不会重复重跑 21 日完整计算。

## 数据文件

- `site/data/latest.json`：最新已验证快照。
- `site/data/history/YYYY-MM-DD.json`：按交易日归档。
- `site/data/universe/`：交易所 ETF 完整名册与每日审计。
- `data_pipeline/classification.json`：可人工审计的分类规则。


## Render

仓库根目录 `render.yaml` 绑定 `main` 分支：

- Build Command: `npm ci && npm run build`
- Publish Directory: `dist`
- Auto Deploy: commit

每次 `main` 上的数据或前端变更通过验证后，会触发 Render 与 GitHub Pages 更新。
