# 数据管道

`update_daily.py` 是唯一生产入口，`classification.json` 是可审计的互斥分类表。

发布检查：交易所全量 ETF 不少于 500 只、沪深两市及合计数量不得较前一交易日异常下降超过 2%、代码不得重复、关键字段不得为空；可明确分类且历史完整的 A 股股票 ETF 不少于 300 只，并取得连续 21 个真实交易日份额。新增、消失、名称变化和待归类产品写入每日审计；完整名册保存到 `site/data/universe/`。收益代理覆盖低于 80% 时快照降级为 warning，关键检查失败时写入 `last-failure.json`，但绝不覆盖 `latest.json`。

AKShare 仅作为采集适配层并固定版本；交易所字段才是份额主源。新浪历史行情的 JavaScript 解码器保持串行调用，避免并发线程安全问题。接口字段一旦发生变化，结构校验会使任务失败。
