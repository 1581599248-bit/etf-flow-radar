# 数据管道

`update_daily.py` 是唯一生产入口，`classification.json` 是可审计的互斥主分类表；A股股票ETF母集先由“指数型-股票”基金类型字段和跨境排除规则确定。`focusEtfFamilies` 仅用于逐只ETF快捷筛选，不参与行业合计；所有未归组股票ETF会自动逐只展示，但已经进入首页全量市场合计。

分类主口径为 `SW2021_L1_ETF_V3`：行业名称与代码采用申万行业分类标准 2021 版 31 个一级行业；只将名称能高置信对应单一一级行业的 ETF 纳入行业汇总。系统仅保留宽基、风格和申万一级行业三类互斥观察组，不设置跨行业主题组；机器人、泛消费、AI 等产品在重点清单中逐只展示，不参与行业资金汇总。

发布检查：交易所全量 ETF 不少于 500 只、沪深两市及合计数量不得较前一交易日异常下降超过 2%、代码不得重复、关键字段不得为空；A股股票ETF全量与互斥分组子集分别对账，并取得连续 21 个真实交易日份额。新增、消失、名称变化和待归类产品写入每日审计；完整名册保存到 `site/data/universe/`。收益代理覆盖低于 80% 时快照降级为 warning，关键检查失败时写入 `last-failure.json`，但绝不覆盖 `latest.json`。

AKShare 仅作为采集适配层并固定版本；交易所字段才是份额主源。新浪历史行情的 JavaScript 解码器保持串行调用，避免并发线程安全问题。接口字段一旦发生变化，结构校验会使任务失败。
